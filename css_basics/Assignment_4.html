CSS Box Model

Padding

Padding

Padding adds space inside the element, between the content and the border.

Border

Border

Border adds a line around the element. You can set the width, style, and color of the border.

Margin

Margin

Margin adds space outside the element, between the element and its neighboring elements.

Box-Sizing: Content-Box

Content-Box

In the content-box model, the width and height properties (150px) include only the content. Padding and border are added to the outside of the box.

Box-Sizing: Border-Box

Border-Box

In the border-box model, the width and height properties (150px) include the content, padding, and border. This can help with consistent sizing.
